# 💊 MediaAlert – Smart Medicine Reminder

MediaAlert is a smart medicine reminder web application designed to help users manage their medications and take them on time.

## 🌟 Features

- 💊 Add and manage medicines
- ⏰ Set personalized medicine reminders
- 🔔 Medicine alarms and notifications
- 📊 Daily medication progress tracking
- 🗣️ Voice assistance
- 🌐 Multilingual support
- 🌙 Dark mode
- 👤 User profile
- 📋 Medicine schedule management
- 📱 Responsive and user-friendly interface

## 🎯 Purpose

MediaAlert aims to help elderly people, patients managing multiple medications, and anyone who may forget their medicine schedule.

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- HTML
- CSS
- JavaScript
- Google AI Studio
- Gemini AI
